# 🏫 Campus Marketplace

A campus-focused marketplace designed to make **buying and selling between students simple, convenient, and accessible**.

Students can list items they no longer need and discover useful products from other students within their campus community.

## ✨ Features

* 🔐 Student authentication
* 📦 Create and manage product listings
* 🖼️ Add product details and images
* 🔎 Search and browse available products
* 🏷️ Browse products by category
* 💰 Set and display item prices
* 👤 User profiles and seller information
* ❤️ Save products for later
* 📱 Responsive and user-friendly interface

## 🎯 Problem

College students regularly buy and sell items such as:

* Textbooks and study material
* Calculators and electronics
* Hostel essentials
* Furniture and appliances
* Sports equipment
* Other useful second-hand items

However, these transactions are often handled through scattered WhatsApp groups, social media, or word of mouth.

**Campus Marketplace brings these transactions into one dedicated platform built around the campus community.**

## 💡 Solution

Campus Marketplace provides students with a centralized platform where they can:

**Sell → List an item → Reach other students**

**Buy → Browse listings → Find what they need**

This makes campus-level buying and selling more organized, searchable, and convenient.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js / Express
* **Database:** MongoDB
* **Authentication:** JWT

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/campus-marketplace.git
cd campus-marketplace
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and add the required configuration:

```env
DATABASE_URL=your_database_url
JWT_SECRET=your_jwt_secret
```

### Run the application

```bash
npm run dev
```

The application will be available locally at:

```text
http://localhost:3000
```
